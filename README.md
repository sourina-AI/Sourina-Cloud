## About

This repository hosts a single-page portfolio case study on **The Narrative Testing Engine** — a Claude-based AI skill and companion app I designed and shipped to validate GTM messaging at scale.

The engine accepts pasted copy, a URL, or an uploaded file, runs a structured persona simulation, scores the narrative against a rubric, and outputs both diagnostic feedback and ready-to-use sales enablement.

## What it solves

Traditional GTM message validation takes weeks — formal user research, persona interviews, qualitative consolidation. By the time signal arrives, the launch window has closed. The Narrative Testing Engine collapses that cycle from weeks to hours.

## How it works

1. **Ingest** — drop in copy, a URL, or a deck
2. **Simulate** — Claude role-plays buyer personas relevant to the product
3. **Surface** — confusion flags, messaging gaps, and competitive positioning issues are graded against a structured rubric
4. **Generate** — sales talk tracks, objection-handling scripts, and revised messaging variants

## Stack

- **AI layer:** Claude (Anthropic) — custom skill, persona-simulation prompting, structured output
- **Frontend:** HTML, CSS (Fraunces + Inter + JetBrains Mono typography)
- **Hosting:** GitHub Pages
